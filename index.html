What is a Shopify App?

Think of Shopify like a smartphone OS. The App Store is where developers publish apps that add features to merchants' stores.

🏪
Shopify = a platform for online stores
The foundation
Shopify lets anyone create an online store without coding. But merchants often need extra features — email popups, loyalty programs, shipping tools, custom widgets. That's where apps come in. You build those apps.
🔌
Two types of apps
Public vs Private
Public apps — listed in the Shopify App Store. Any merchant can install them. Great for generating income.

Custom/Private apps — built for one specific store. Good for freelance work or your own store.
⚙️
What apps actually do
Under the hood
Apps talk to Shopify using an API (a way for software to communicate). Your app can read/write store data — products, orders, customers — and add a UI panel inside the Shopify admin dashboard.
Your path as a beginner: HTML/CSS you know → learn JavaScript → learn Node.js (JavaScript for servers) → learn React (optional but common) → learn Shopify's API & toolkit. You're closer than you think!
Core Concepts to Understand

These are the building blocks. Don't worry about memorising them — just get a feel for each one.

🔑
OAuth
How a merchant gives your app permission to access their store. Like "Login with Google" but for Shopify stores.
🌐
REST & GraphQL API
Two ways to request data from Shopify. Think of them as two different menu formats at a restaurant.
📣
Webhooks
Shopify sends your app a notification when something happens — like a new order. Your app listens and reacts.
🖼️
Embedded App
Your app's UI lives inside the Shopify admin dashboard. Shopify provides a toolkit called App Bridge for this.
🏪
Theme Extensions
Adds UI blocks directly to the storefront (what shoppers see). Built with Liquid — Shopify's template language.
🔐
Access Scopes
When your app installs, you request only the permissions you need — like read_orders or write_products.
Don't panic! You won't learn all of this at once. The Shopify CLI (a command-line tool) and starter templates do most of the heavy lifting for you while you're learning.
Your Tool Belt

Here's exactly what you'll use to build Shopify apps — from your laptop to production.

🧰
Shopify CLI Start here
A command-line tool that scaffolds your entire app in seconds. One command creates a working app template with auth, routing, and API calls already wired up.
# Install and create your first app npm install -g @shopify/cli shopify app init
⚛️
Node.js + React Learn next
Node.js — runs JavaScript on a server (your app's backend). Handles OAuth, API calls, webhooks.

React — builds the UI your merchant sees. You already know HTML — React is like HTML with superpowers and live updates.
💜
Polaris — Shopify's UI Kit Free to use
Shopify provides a ready-made component library called Polaris. Pre-built buttons, tables, forms, modals that match Shopify's design system. You don't have to style your admin app from scratch!
import { Button, Card, Page } from '@shopify/polaris'; export default function MyPage() { return ( <Page title="My App"> <Card>Hello Shopify!</Card> </Page> ); }
🌍
Deployment — Render / Fly.io / Vercel When ready
Your app needs to be hosted on the internet so Shopify stores can connect to it. These platforms make that easy and have free tiers for getting started.

Your First Real Code

Here's what a simple Shopify app page looks like — annotated for beginners. This fetches and displays a store's products.

📦
Fetch & display products
app/routes/app._index.jsx
// 1. Import Shopify tools and React components import { useLoaderData } from "@remix-run/react"; import { Page, Card, DataTable } from "@shopify/polaris"; import { authenticate } from "../shopify.server"; // 2. loader() runs on the server — fetches data before the page loads export const loader = async ({ request }) => { // Authenticate the merchant making the request const { admin } = await authenticate.admin(request); // Ask Shopify for the first 10 products (GraphQL query) const response = await admin.graphql(` query { products(first: 10) { edges { node { id title status } } } } `); const { data } = await response.json(); return data.products.edges; }; // 3. The page component — receives loaded data as a prop export default function Index() { const products = useLoaderData(); return ( // Page and Card are Polaris components — no CSS needed! <Page title="My Products"> <Card> <DataTable columnContentTypes={['text', 'text']} headings={['Product', 'Status']} rows={products.map(({ node }) => [node.title, node.status])} /> </Card> </Page> ); }
What's happening here? The loader function runs on your server, authenticates the merchant, calls Shopify's API to get products, then passes the data to your React page component which renders it in a nice table — all with Polaris components you didn't have to style yourself.
Glossary

Click any term to expand its definition. Bookmark this as your reference.

API
Application Programming Interface. A set of rules that lets your app communicate with Shopify's servers. When your app asks "give me all orders", it's making an API call.
OAuth
A security protocol for granting access. When a merchant installs your app, OAuth handles the permission dance — "do you allow this app to read your orders?" — without sharing passwords.
GraphQL
Shopify's preferred API style. Instead of getting all data, you ask for exactly what you need. Like ordering a custom burger vs getting a set meal.
Webhook
A push notification from Shopify to your app. When a new order is placed, Shopify sends a webhook to your server so you can react in real time.
App Bridge
Shopify's JavaScript library that lets your app communicate with the Shopify Admin UI — things like navigation, toast messages, modals that feel native to Shopify.
Polaris
Shopify's open-source React component library. Pre-built UI elements (buttons, cards, tables) that match Shopify's design. You use these to build your admin app's interface.
Remix
A full-stack React framework that Shopify's CLI uses by default. It handles routing, server logic, and data loading in a clean, modern way. You'll get comfortable with it as you go.
Liquid
Shopify's templating language for storefronts. If you want to modify what shoppers see (not just the admin), you'll use Liquid. It looks like HTML with extra tags like {% for %} and {{ variable }}.
Shopify Partner
A free account for developers and agencies who build on Shopify. Gives you access to development stores, the app submission process, and revenue sharing if you publish apps.
Access Scopes
Permissions your app requests. Like phone app permissions — you declare upfront "I need read_products and write_orders", and merchants see exactly what your app can touch.
